## Visiting the website

The website provides information pages without its own user accounts, registration form or user database. The inspected website files load images, CSS and JavaScript from the same host; no external fonts or embedded services were found in those files. This does not mean that visiting the website involves no personal data processing.

Cloudflare Pages hosts the website. Delivery involves processing an IP address and HTTP request information, such as the requested address, time and browser information. The purpose is to deliver the pages. Article 6(1)(f) GDPR is being considered for necessary website delivery, with the legitimate interest of providing an available, functioning information resource. This assessment does not cover unresolved additional logging or analysis purposes.

## Technical network reports

The inspected responses include NEL and Report-To headers pointing to a Cloudflare endpoint on `a.nel.cloudflare.com`. Supporting browsers may send network reports, for example with a requested URL, error, protocol, status and connection duration. An IP address is processed when a report is received. The purpose is to diagnose connection problems.

According to [Cloudflare's NEL documentation](https://developers.cloudflare.com/network-error-logging/), the client IP remains in volatile memory only while a request is processed and is not logged in the NEL pipeline. This is the provider's statement about NEL, rather than about all Cloudflare logs. The observed browser policy lasts seven days (`max_age=604800`); this is not a server retention period. Actual report transmission, server retention and the legal basis, including the assessment under section 25 TDDDG, still need clarification.

## Appearance and local storage

The appearance button stores `dark` or `light` in this origin's localStorage under `site-theme` only after you make a choice. On page load, the existing value is read without being written again. Without a valid choice, appearance follows the system preference. The website code does not send the saved theme value to a server.

There is no automatic expiry. The value remains until it is overwritten, website data are cleared or the browser removes it. You can delete it through your browser's website data settings. If storage is blocked, the appearance control continues to work for the current page.

The exception in section 25(2), number 2 TDDDG is used for the explicitly requested persistent appearance setting. It does not authorise storage for other purposes. No consent banner is used for this function; the unresolved NEL assessment is separate. This section describes the prepared website code.
