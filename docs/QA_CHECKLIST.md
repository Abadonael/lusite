# Проверки сайта

Этот файл описывает ручные и доступные автоматические проверки. Он не означает,
что они уже выполнены. Отмечай результаты для конкретной задачи или релиза.

## Какие проверки выбирать

| Изменение | Обязательные проверки |
|---|---|
| Только документация | Правильность сведений, относительных ссылок и git diff |
| Статьи | Сборка, содержание, список статей, ссылки, тема и поведение языков |
| Переводы | Предыдущее плюс соответствие переводов, переходы и метаданные языков |
| Шаблоны, CSS или JS | Сборка и все пользовательские проверки ниже |
| Impressum и Datenschutz | Сборка, содержание, футер, мобильный вид и актуальность данных |
| Cookies, внешние ресурсы или формы | Предыдущее плюс проверка сети и хранилища браузера |
| Публикация | Успешный deployment и короткая проверка на production |

## Сборка и маршруты

- [ ] Сборка существующей командой проекта завершается без ошибок.
- [ ] Главная, список статей, тема «Аллергия» при наличии и семь статей открываются.
- [ ] Переход `/` ведёт на `/ru/` на правильном хосте.
- [ ] В актуальной сборке нет ссылок и редиректов на `kuranova.synology.me`.
- [ ] Нет внутренних ссылок на несуществующие страницы и изображения.
- [ ] Неизвестный URL показывает корректную страницу 404.
- [ ] Canonical, sitemap и hreflang при наличии используют правильный домен
      и только реально существующие языковые страницы.

## Статьи

- [ ] Все семь статей доступны из списка, без дубликатов.
- [ ] Три аллергологические статьи относятся к теме «Аллергия».
- [ ] Остальные четыре не получили выдуманную тему.
- [ ] Заголовки, абзацы, списки, числа, единицы и медицинские термины
      соответствуют утверждённому тексту.
- [ ] Содержание не обрезано; служебный план из ODT не опубликован как статья.
- [ ] Добавление материала не изменило оформление старых статей.

## Языки

- [ ] На главной и списках проверены переходы между доступными RU, DE и EN.
- [ ] На переведённой статье переключатель ведёт к её эквиваленту.
- [ ] На новой статье без переводов нет фиктивных DE/EN страниц и 404.
- [ ] Текущее поведение при отсутствии перевода понятно посетителю.
- [ ] Нет случайной смеси языков в меню и кнопках; доступность юридических
      страниц соответствует зафиксированной языковой стратегии.
- [ ] HTML `lang` соответствует языку страницы.

## Светлая и тёмная темы

- [ ] Проверен первоначальный режим в новом профиле браузера.
- [ ] Обе темы работают на главной, списке, статье и юридической странице.
- [ ] После ручного выбора режим сохраняется при переходе и перезагрузке,
      если браузер разрешает используемое хранилище.
- [ ] Переключение языка не сбрасывает выбор темы на том же хосте.
- [ ] При недоступном хранилище страница и переключатель продолжают работать.
- [ ] В обеих темах читаются текст, ссылки, кнопки, меню и состояние фокуса.
- [ ] Нет заметной вспышки неправильной темы при загрузке.
- [ ] Если поддерживается системная тема, проверено её фактическое поведение.

## Экран и управление

- [ ] Проверены узкий экран около 360 px и компьютерный около 1280 px.
- [ ] Нет горизонтального прокручивания страницы и наложения элементов.
- [ ] Мобильное меню, язык, тема и футер доступны.
- [ ] Основные элементы доступны клавиатурой; фокус виден.
- [ ] При увеличении масштаба до 200% содержимое остаётся читаемым.
- [ ] У содержательных изображений есть осмысленный alt; у кнопок-иконок
      есть доступные названия.

## Конфиденциальность

Проверять в чистом профиле на опубликованном сайте. Локальная версия может
не включать настройки и инъекции Cloudflare. Дополнительно проверить загрузку
после взаимодействия с меню, темой и любыми встроенными компонентами.

- [ ] Зафиксированы сторонние домены, cookies, localStorage и sessionStorage.
- [ ] Выяснено назначение каждого элемента; наличие и цель не угаданы по имени.
- [ ] Политика описывает реальные подключения и настройки хостинга.
- [ ] Если согласие не требуется, есть обоснованное решение по найденным
      операциям, а не только вывод «cookies не обнаружены».
- [ ] Если согласие требуется, соответствующие операции не запускаются до выбора.
- [ ] В consent-интерфейсе при наличии доступны отказ, настройка и отзыв согласия;
      отказ не скрыт и не сложнее принятия.
- [ ] После отказа и отзыва повторно проверены сеть и хранилище.
- [ ] Impressum и Datenschutz доступны независимо от выбора согласия.

## После push

- [ ] Cloudflare завершил именно deployment нужного commit успешно.
- [ ] Production открывается; проверены главная, одна новая статья и футер.
- [ ] Проверены тема и доступный переход языка.
- [ ] Для preview при его использовании нет редиректа на production.
